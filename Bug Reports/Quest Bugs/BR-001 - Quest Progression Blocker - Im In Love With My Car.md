# BR-001 – Quest Progression Blocker – "I'm In Love With My Car"

> **Portfolio Note:** This is a fictional QA portfolio example inspired by publicly released gameplay. It is not based on confidential information.

## Game
Cyberpunk 2077

## Platform
PC (Steam)

## Build
Version 2.x

## Category
Quest Progression

## Severity
Critical

## Priority
High

## Frequency
5/5

## Description
The player is unable to interact with the quest vehicle after reaching the objective marker, preventing further quest progression.

## Preconditions
- Existing save file
- Quest is active
- Player has reached the objective marker

## Steps to Reproduce
1. Launch the game.
2. Load the affected save.
3. Track the quest 'I'm In Love With My Car'.
4. Travel to the quest marker.
5. Attempt to interact with the vehicle.

## Expected Result
The interaction prompt appears and the quest advances.

## Actual Result
No interaction prompt appears and the vehicle remains locked.

## Impact
The player cannot complete the quest without a workaround or future patch.

## Suggested Verification
- Reload checkpoint
- Restart the game
- Fast travel away and return
- Verify on a fresh save
