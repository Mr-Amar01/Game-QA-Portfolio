# TC-PUBG-005 – Verify Performance During Extended Session

## Module
Performance

## Priority
High

## Type
Performance / Soak

## Objective
Verify that the game maintains acceptable frame-rate stability and responsiveness during an extended play session.

## Preconditions
- Supported test device.
- Fixed graphics and frame-rate settings.
- Performance monitoring available.

## Steps
1. Start from a cool device state.
2. Record baseline performance in a controlled scenario.
3. Play multiple consecutive matches without restarting the application.
4. Repeat the controlled scenario periodically.
5. Compare frame-rate stability, input response and device temperature.

## Expected Result
Performance remains within the defined acceptance range for the selected settings.

## Pass Criteria
No unacceptable performance degradation or thermal-related instability occurs.
