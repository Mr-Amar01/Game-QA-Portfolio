# TC-PUBG-004 – Verify Audio Recovery After Incoming Call

## Module
Audio / Mobile Interruption

## Priority
Medium

## Type
Recovery / Functional

## Objective
Verify that game audio resumes correctly after an incoming call interrupts gameplay.

## Preconditions
- Active match.
- Game audio enabled.
- Device can receive calls.

## Steps
1. Join an active match.
2. Confirm game audio and voice settings.
3. Trigger or simulate an incoming call.
4. Dismiss the call.
5. Return to the game.
6. Check game and voice audio.

## Expected Result
Audio resumes according to the configured settings.

## Pass Criteria
No persistent mute, incorrect volume or audio-session failure occurs.
