# TC-QST-001 – Verify Quest Vehicle Interaction

## Module
Quest System

## Type
Functional

## Priority
High

## Objective
Verify that the player can interact with the quest vehicle after reaching the destination.

## Preconditions
- Quest available
- Valid save file
- Player can freely travel

## Test Steps
1. Launch Cyberpunk 2077.
2. Load the save file.
3. Accept the quest.
4. Reach the objective.
5. Attempt to interact with the vehicle.

## Expected Result
The interaction prompt appears, the player enters the interaction sequence, and the quest progresses to the next objective.

## Pass Criteria
Quest progresses without requiring a reload or workaround.

## Priority
High
