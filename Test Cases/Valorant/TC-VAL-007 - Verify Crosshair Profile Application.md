# TC-VAL-007 – Verify Crosshair Profile Application

## Module
Settings / Crosshair

## Priority
Medium

## Type
Functional

## Objective
Verify that selecting a saved crosshair profile immediately applies the correct configuration in gameplay.

## Preconditions
- At least two distinct crosshair profiles are configured.

## Steps
1. Open crosshair settings.
2. Apply profile A.
3. Enter gameplay and observe the crosshair.
4. Return to settings.
5. Apply profile B.
6. Return to gameplay.

## Expected Result
The crosshair immediately matches the selected profile after returning to gameplay.

## Pass Criteria
No stale crosshair configuration remains after switching profiles.
