# TC-VAL-005 – Verify Post-Match Statistics

## Module
Match Results / UI

## Priority
Medium

## Type
Functional

## Objective
Verify that the post-match screen displays the final statistics recorded during the completed match.

## Preconditions
- Match can be completed.

## Steps
1. Complete a match.
2. Open the post-match results screen.
3. Record displayed statistics.
4. Navigate away from the screen.
5. Return to the results screen.
6. Compare the values.

## Expected Result
The same final match statistics are displayed consistently.

## Pass Criteria
No stale or inconsistent values appear between views.
