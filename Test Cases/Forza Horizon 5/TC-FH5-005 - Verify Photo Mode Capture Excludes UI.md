# TC-FH5-005 – Verify Photo Mode Capture Excludes UI

## Module
Photo Mode

## Type
Functional / UI

## Priority
Low

## Objective
Verify that captured photos contain the intended scene without photo mode controls or transient interface elements.

## Preconditions
- Photo Mode available.
- Capture function available.

## Steps
1. Enter Photo Mode.
2. Adjust camera settings.
3. Move the camera and wait for the interface to stabilize.
4. Capture an image.
5. Review the saved image.

## Expected Result
Only the intended scene is included in the captured image.

## Pass Criteria
No photo mode UI or transient controls appear in the final image.
