# TC-FH5-001 – Verify Race Checkpoint Registration

## Module
Race System

## Type
Functional

## Priority
High

## Objective
Verify that checkpoints register correctly when the vehicle crosses the intended checkpoint trigger during a race.

## Preconditions
- Race event with checkpoints available.

## Steps
1. Start the race.
2. Follow the intended route.
3. Approach each checkpoint at different speeds.
4. Cross each checkpoint.
5. Confirm race progression.

## Expected Result
Every valid checkpoint registers once and the race route advances correctly.

## Pass Criteria
No valid checkpoint is missed during normal driving.
