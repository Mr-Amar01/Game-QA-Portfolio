# TC-RDR2-004 – Verify Weapon Wheel Selection State

## Module
Weapon System / UI

## Priority
Medium

## Type
Functional

## Objective
Verify that the weapon wheel accurately reflects the currently equipped weapon.

## Preconditions
- Player has multiple weapons available.

## Steps
1. Open the weapon wheel.
2. Select a weapon.
3. Close the wheel.
4. Change the equipped weapon through gameplay.
5. Reopen the weapon wheel.
6. Compare the selection indicator with the equipped weapon.

## Expected Result
The wheel always reflects the current equipped weapon.

## Pass Criteria
No stale selection indicator or incorrect weapon state is displayed.
