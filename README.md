## 🐛 Bug Report Standard

Each defect is structured around information needed to reproduce and assess an issue:

- Bug ID and concise title
- Environment / platform
- Category
- Severity and priority
- Preconditions
- Reproduction steps
- Expected vs. actual result
- Reproduction rate
- Player / system impact
- Verification considerations where relevant

## 🧪 Test Case Standard

Test cases generally include:

- Test Case ID
- Module
- Test type
- Priority
- Objective
- Preconditions
- Test steps
- Expected result
- Pass criteria
