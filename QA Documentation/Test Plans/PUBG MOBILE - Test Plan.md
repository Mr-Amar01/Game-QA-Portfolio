# PUBG MOBILE – Test Plan

> Simulated portfolio document for QA demonstration.

## Objective
Validate gameplay, touch controls, matchmaking, networking, mobile lifecycle behavior, UI, performance and recovery across supported mobile configurations.

## Scope
- Touch controls and HUD
- Match flow and matchmaking
- Weapons and inventory
- Movement and vehicles
- Network recovery
- Background/foreground transitions
- Audio interruptions
- Resource downloads
- Performance and thermal stability

## Device Coverage
Use a representative matrix of low-, mid- and high-tier supported Android devices, screen aspect ratios and OS versions.

## Test Types
Functional, compatibility, regression, smoke, recovery, performance, network and exploratory testing.

## Entry Criteria
Installable build available, supported devices prepared, test accounts available and network profiles configured.

## Exit Criteria
Critical flows executed, high-severity defects documented, compatibility coverage completed and release-blocking issues triaged.

## Key Risks
Device fragmentation, thermal throttling, network variability, background process termination and storage constraints.

## Deliverables
Bug reports, device matrix, test execution results, regression results and QA summary.
