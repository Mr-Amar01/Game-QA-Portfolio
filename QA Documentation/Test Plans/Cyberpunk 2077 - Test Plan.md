# Cyberpunk 2077 – Test Plan

> Simulated portfolio document for QA demonstration. It does not represent confidential production documentation.

## 1. Objective
Validate core gameplay, quest progression, combat, vehicles, UI, save/load, AI and stability across representative PC configurations.

## 2. Scope
- Main and side quest progression
- Character movement and combat
- Weapons, inventory and crafting
- Vehicles and open-world traversal
- NPC AI and interactions
- UI and HUD
- Save/load and checkpoints
- Audio and visual presentation
- Basic performance and stability

## 3. Out of Scope
- Backend infrastructure testing
- Source-code testing
- Internal developer tools
- Unreleased features

## 4. Test Types
Functional, regression, smoke, exploratory, compatibility, performance, usability and recovery testing.

## 5. Entry Criteria
Build is installable, game launches, test accounts/saves are available and critical blockers from the previous cycle are understood.

## 6. Exit Criteria
Planned test cases executed, critical blockers triaged, high-priority defects documented and no unresolved release-blocking issue remains within the agreed scope.

## 7. Risks
- Large open-world state combinations
- Save-state dependency
- Streaming and performance variability
- Quest progression dependencies

## 8. Deliverables
Bug reports, test execution results, regression results, smoke results and final QA summary.
