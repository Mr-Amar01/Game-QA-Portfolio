# Mobile Device Compatibility Matrix

> **Sample portfolio matrix.** Device names/results are illustrative and should be replaced with actual execution data before presenting as measured results.

| Device Tier | OS Range | Screen Profile | Graphics Profile | Areas |
|---|---|---|---|---|
| High-end | Current supported Android | High resolution / high refresh | High | Gameplay, performance, thermal |
| Mid-range | Supported Android | Standard widescreen | Medium | Gameplay, UI, performance |
| Entry-level | Supported Android | Standard resolution | Low | Stability, memory, loading |
| Large-screen | Supported Android | Large display | Medium | HUD, menus, scaling |

## Compatibility Checks
- Installation and update
- Launch and login
- HUD scaling
- Touch controls
- Graphics settings
- Audio
- Matchmaking
- Gameplay stability
- Background/resume
- Network recovery
- Resource downloads
- Performance

## Result Convention
**Pass:** Expected behavior on the tested configuration.

**Fail:** Reproducible deviation requiring investigation.

**Blocked:** Execution prevented by an environment or dependency issue.
