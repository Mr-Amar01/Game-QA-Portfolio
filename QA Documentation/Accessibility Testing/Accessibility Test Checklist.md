# Accessibility Test Checklist

> Simulated portfolio checklist.

## Visual
- [ ] Subtitle visibility
- [ ] Text readability
- [ ] UI contrast
- [ ] Color-dependent information has an alternative where supported
- [ ] Important indicators remain distinguishable

## Input
- [ ] Controller/input remapping where supported
- [ ] Touch controls remain usable
- [ ] Adjustable sensitivity where supported
- [ ] Repeated input does not create unintended behavior

## Audio
- [ ] Subtitles can be enabled
- [ ] Subtitle timing is understandable
- [ ] Important audio information has supported visual alternatives
- [ ] Separate volume controls work correctly where available

## Settings Persistence
- [ ] Accessibility settings persist after restart
- [ ] Settings persist after loading a save/profile
- [ ] Reset-to-default behavior works

## Reporting
Document platform, accessibility setting, reproduction steps, expected behavior and actual behavior. Avoid assuming a feature is required when it is not supported by the product/platform.
